The problem

A relationship-management app needs a way to recognize changing communication patterns. The model’s question is specific: does past contact history help predict an extended gap in future communication?

What I built

A scikit-learn gradient-boosting model using features derived from interaction timestamps and direction. The model evaluates communication cadence rather than the meaning or emotional tone of messages.

How I evaluated it

The model achieved 0.906 ROC-AUC on participants excluded from training. ROC-AUC measures how well a model separates outcomes across decision thresholds. It is not a percentage-accuracy score.

From Python to the app

Integrated predictions into the application through TypeScript, with tests that compare the implementation against Python outputs. The application uses Supabase.

A deliberate boundary

The model withholds scores when contact history is insufficient. It predicts observed communication gaps and does not claim to measure the quality or health of a relationship.
