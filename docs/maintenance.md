# Maintenance

The site uses static HTML, CSS and JavaScript with no package dependencies.

## Publishing

1. Preview the changes using the commands in [README.md](../README.md).
2. Check syntax, local asset paths and project links.
3. Push reviewed changes to `main`.
4. Confirm the GitHub Pages deployment succeeds.

## Content

Keep project summaries aligned with the linked repositories. Update contact links
and project descriptions when they change. Preserve asset licenses and notices.

Report security issues through [SECURITY.md](../SECURITY.md).
