The problem

Bank statement PDFs are designed to be read, but their transactions often need to be checked and analyzed in a spreadsheet. Manual copying adds repetitive work and opportunities for errors.

What I built

A Python workflow that uses LangGraph and Claude to extract transaction data from PDFs and export it to Excel. Pydantic schema validation checks the structure of the extracted records.

How it works

The workflow separates extraction from validation, checks for duplicates, and can retry when a response does not meet the expected structure. Review flags identify records that need a person’s attention.

Security and review

Upload size limits, file-path checks, Unicode normalization, and separation of instructions from document content reduce the risks of processing untrusted files. These checks complement human review of the extracted data.

Where it fits

This work sits alongside my private P&L reconciliation project at Ardinall Hedge Fund. For that separate tool, I demonstrated the workflow to the CFO and trained users to interpret the outputs.
