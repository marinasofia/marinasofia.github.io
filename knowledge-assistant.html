Ask me about this project ↗

The problem

When policies live across documents and versions, finding a relevant answer also means knowing which source to trust.

What I built

A workspace for ingesting text and Markdown documents, managing versions, and searching approved content through a React interface and FastAPI REST APIs. Search results show the source passages so a user can inspect the evidence.

How it works

Hybrid search combines keyword matching with vector retrieval using MiniLM embeddings. A configurable Claude retrieval-augmented generation (RAG) integration uses retrieved passages as context. Citation checks validate source references and exact quotes.

Where people stay involved

Unresolved questions can enter an administrator review workflow. Role-based access controls and PostgreSQL row-level security separate workspaces and limit access to documents.

How I checked it

The release documentation records 23 automated backend tests covering document handling, access controls, and data isolation, alongside four end-to-end browser workflows.

Project scope

This is a development project with a private source repository. The default mode retrieves source passages. The Claude integration is configurable, and live paid Claude calls were not tested in the documented build.
