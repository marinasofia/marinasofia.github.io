Projects

  1. Sourcer2026

    A lead engine that reads 405 company career sites every morning, rules out what doesn't fit me with plain rules, scores the rest against my profile and texts me the best match. When I apply, it tailors my resume from facts I've approved.

    In one run on Oct 11 it read 40,118 postings and only 1,801 got past the rules. Three decisions shaped it. A posting is ruled out only on an explicit signal, because a wrong drop is a job I never see. A hard cost cap is checked before every model call. Every model answer gets one corrective retry, never two. A test set of 322 labelled postings fails the build if any score drops. Code on GitHub.

  2. Knowledge Assistant2026

    A workspace where a team asks questions about its own policies and gets back the exact approved passage that answers them. When two policies disagree it shows both, and when nothing covers the question it refuses instead of guessing.

    10 of 10 unanswerable questions refused, 25 of 25 answerable ones answered, on 60 labelled questions with a held out set. Every workspace is locked twice, in the app and in Postgres row level security, with 85 backend tests, 8 browser tests and a threat model in CI. Code on GitHub.

  3. Rekindle2026

    Predicts which relationships are fading and texts you first in iMessage. It drafts what to say and sends from your own number only after you reply yes. The agent asks for consent before any model call, handles STOP and PAUSE before the model sees a message, and fences off text other people wrote so a contact can't steer it.

    0.906 ROC AUC on people the model never saw, across 112,137 moments, measured inside the private project. A SEND rate measures which drafts get sent and answered, without storing message text. Private project, demo on request.

    TypeScript · Python · scikit-learn · Supabase · Postgres · Claude · iMessage
