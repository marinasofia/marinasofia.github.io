The problem

Job openings are scattered across applicant tracking systems. Comparing roles and connecting each requirement to actual experience creates repetitive work.

What I built

A LangGraph workflow with adapters for six applicant tracking systems, scheduled job collection, deduplication, and retries. The public showcase explains the workflow using synthetic examples.

From discovery to a draft

The workflow organizes relevant roles and supports application drafts grounded in the candidate’s evidence. Budget limits and duplicate checks help control repeated processing.

What this demo shows

The interactive example above uses fictional jobs and a template introduction to show the experience. It does not fetch live openings, call a language model, or submit applications.
